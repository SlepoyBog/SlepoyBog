## Избранные проекты

### I · [Oleg Assistant](https://github.com/SlepoyBog/oleg-assistant-portfolio)

Telegram-помощник: задачи, SQLite и недельный Excel-план для руководителя. Авторизация владельца, резервные копии и восстановление после сетевых сбоев. Публичная версия прошла все 16 тестовых файлов.

### II · [Glass Monitor Demo](https://github.com/SlepoyBog/glass-monitor-demo)

Автономное приложение на PowerShell для учёта ресурса защитных стёкол и производственных показателей. CSV/XLSX-отчёты, Windows OCR, USB-обновления и контроль целостности. Рабочая версия внедрена на двух местах; здесь опубликовано обезличенное демо.

### III · [AI Content Farm](https://github.com/SlepoyBog/Farm)

Python-конвейер подготовки, проверки и публикации AI-контента. Интеграции с LLM и API площадок, GitHub Actions, GitHub Pages, сохранение состояния и восстановление. 55 автоматических тестов. Проект приостановлен. [Демонстрация](https://slepoybog.github.io/Farm/).

### IV · [Интерактивная раскладка труб](https://github.com/SlepoyBog/pallet-layout-demo)

HTML/JavaScript-инструмент с 3D-схемой для сравнения вариантов укладки. Проверки пересечений и габаритов: 12 демонстрационных позиций, 734 состояния. [Демонстрация](https://slepoybog.github.io/pallet-layout-demo/).

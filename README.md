## Основные проекты

### [Oleg Assistant](https://github.com/SlepoyBog/oleg-assistant-portfolio)

Локальный Telegram-помощник на Python для сбора задач, планирования рабочего дня и формирования Excel-плана.

- Python, Telegram Bot API, SQLite, Excel;
- авторизация владельца, резервные копии и восстановление после сетевых сбоев;
- 16 сценарных тестов;
- ежедневный план используется в рабочем процессе.

### [Glass Monitor Demo](https://github.com/SlepoyBog/glass-monitor-demo)

Обезличенная версия Windows-приложения для учёта ресурса защитных стёкол и производственных показателей лазерных станков.

- PowerShell 5.1, WinForms, Windows OCR, CSV/JSON, Open XML;
- автономная работа без интернета и перенос обновлений через USB;
- контрольные суммы, резервное восстановление и встроенные самопроверки;
- рабочая версия внедрена на двух местах.

### [AI Content Farm](https://github.com/SlepoyBog/Farm)

Приостановленный Python-проект автоматической подготовки, проверки, публикации и анализа AI-контента.

- интеграции с LLM, Telegram, VK, OK и Dzen;
- GitHub Actions, автоматические тесты, recovery-артефакты и GitHub Pages;
- 55 тестовых сценариев и более 600 коммитов;
- метрики, health report и контур обратной связи.

### [Интерактивная раскладка труб](https://github.com/SlepoyBog/pallet-layout-demo)

Автономный браузерный инструмент для предварительного сравнения вариантов укладки трубных заготовок в поддон.

- интерактивная 3D-схема и два дополнительных проекционных вида;
- расчёт количества, массы, высоты, выступания и положения центра массы;
- проверка пересечений и выхода за габариты при ручном перемещении;
- 12 демонстрационных типоразмеров и 734 автоматически проверяемых состояния.
